Oracle-Native-Standby Standby Manager

Interactive:
  oracle-native-standby
  oracle-native-standby menu
  oracle-native-standby full-build

Complete build:
  oracle-native-standby full-build
  oracle-native-standby full-build --non-interactive

Submit ALL tasks at once:
  oracle-native-standby all --background
  oracle-native-standby all --foreground
  oracle-native-standby resume-all <job-id> --background
  oracle-native-standby plan

Build:
  oracle-native-standby build
  oracle-native-standby build --background
  oracle-native-standby resume <job-id>
  oracle-native-standby resume <job-id> --background

Job tracking:
  oracle-native-standby jobs
  oracle-native-standby status <job-id>
  oracle-native-standby logs <job-id>
  oracle-native-standby wait <job-id>
  oracle-native-standby stop <job-id>

Individual operations:
  oracle-native-standby preflight
  oracle-native-standby precheck
  oracle-native-standby placeholder
  oracle-native-standby dg-validate
  oracle-native-standby sync

Environment/config:
  CONFIG_FILE=/path/standby.env
  STANDBY_BUILD_METHOD=ACTIVE_DUPLICATE|OFFLINE_BACKUP
  TARGET_RAC_ENABLED=YES|NO

Driver file:
  Default location: conf/oracle-native-standby.drv

  -d, --driver FILE
  --drv FILE
      Load all standby input values from oracle-native-standby.drv.

  oracle-native-standby drv-all --background
      Uses conf/oracle-native-standby.drv automatically.
      If the file does not exist, prompts for all required values,
      creates conf/oracle-native-standby.drv, then submits the build.

  oracle-native-standby -d ./oracle-native-standby.drv all --background
  oracle-native-standby --driver ./oracle-native-standby.drv plan

Driver utilities:
  oracle-native-standby driver-template [FILE]
  oracle-native-standby driver-validate FILE
  oracle-native-standby driver-show FILE

Precedence:
  conf/standby.env < oracle-native-standby.drv < explicit CLI switches

Non-interactive input switches:
  -s, --source-db-name NAME
  -u, --source-db-unique-name NAME
  -S, --source-sid SID
  -H, --source-host HOST
  -O, --source-oracle-home PATH
  -r, --source-service SERVICE

  -t, --target-db-name NAME
  -U, --target-db-unique-name NAME
  -T, --target-sid SID
  -h, --target-host HOST
  -o, --target-oracle-home PATH
  -R, --target-service SERVICE

  -m, --method ACTIVE_DUPLICATE|OFFLINE_BACKUP
  -p, --platform AUTO|BASE_DB_SERVICE_DBCLI|GENERIC_OCI_OR_SELF_MANAGED
  --source-os-user USER
  --target-os-user USER
  --target-provision-user USER
  --source-port PORT
  --target-port PORT
  --target-aux-port PORT
  --target-aux-listener NAME
  --source-tns-alias ALIAS
  --target-tns-alias ALIAS
  --db-create-file-dest DEST
  --fra DEST
  --fra-size SIZE
  --source-backup-stage PATH
  --target-backup-stage PATH
  --copy-method SCP|RSYNC|NFS
  --rac YES|NO
  --rac-instances N
  --grid-home PATH
  --undo-prefix NAME
  --redo-size-mb MB
  --sync-wait SECONDS
  --sync-poll SECONDS
  --source-tde-wallet PATH
  --target-tde-wallet PATH
  --dg-archive-dest-id N
  --config FILE

Secrets (supported but environment/secret manager is recommended):
  --source-sys-password PASSWORD
  --target-sys-password PASSWORD
  --target-admin-password PASSWORD

Example:
  oracle-native-standby \
    -s ORCL -u ORCLPRD -S ORCL1 -H primary1 -O /u01/app/oracle/product/19c/dbhome_1 \
    -r ORCLPRD \
    -t ORCL -U ORCLSTBY -T ORCL1 -h standby1 -o /u01/app/oracle/product/19c/dbhome_1 \
    -R ORCLSTBY -m ACTIVE_DUPLICATE -p AUTO --rac NO \
    all --background
